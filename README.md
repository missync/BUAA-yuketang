# BUAA 雨课堂辅助工具

适用于雨课堂新版课程页面的 Tampermonkey 脚本。

## 功能

- 三种模式：观看并答题、只观看、只答题；运行时只能暂停，暂停后可重新选择模式。
- 视频按目录顺序以 2 倍速播放，支持后台续播、断点恢复并跳过已完成项。
- 题间额外随机等待 2.5–3.5 秒，仍保留题目稳定和提交确认检查。
- 通过多模态模型读取题图，作答单选、多选和判断题；填写后核对选项，确认提交成功再继续。
- 不支持的题型、需人工操作或缺少视频内容的题直接留空跳过；作业保留未完成，题号见 API 设置中的跳过清单。

## 使用

1. 在 Chrome 安装 Tampermonkey，新建脚本，复制 [yuketang.js](./yuketang.js) 全文并保存，然后刷新课程页面。
2. 需要答题时，打开“API 设置”，填写 Key 并保存。默认模型为 `deepseek-flash`，默认地址为 `https://api.deepseek.com/v1/chat/completions`；自定义模型必须支持图片输入。只观看无需 API。
3. 选择模式并点击“开始”；点击“暂停”停止。建议同一课程只在一个标签页运行。

## 人机验证与异常

检测到验证码、人机验证，或出现接口、提交、播放等异常时，脚本会停止所有任务，按钮恢复“开始”，模式恢复可选。

随机间隔不能保证不触发验证。请手动完成验证或排除故障，检查当前题目的提交状态后，再点击“开始”。脚本不会自动完成验证或自动恢复运行；验证码也不会作为普通人工题跳过。
